# Installation

Pocket Timer installs the same way on every platform.

## macOS

Run `pipx install pocket-timer`.

## Linux

Run `pipx install pocket-timer`.

## Windows

Run `pipx install pocket-timer`.

## Verify the installation

Run `pocket --version`. Pocket Timer prints its version number when the installation works.
