# Instalación

Pocket Timer se instala de la misma forma en todas las plataformas.

## macOS

Ejecuta `pipx install pocket-timer`.

## Linux

Ejecuta `pipx install pocket-timer`.

## Windows

Ejecuta `pipx install pocket-timer`.

## Verifica la instalación

Ejecuta `pocket --version`. Si la instalación funciona, Pocket Timer muestra su número de versión.
